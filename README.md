📊 Task 3: Top 10 Tweets by Engagement
📌 Description

This task identifies the top 10 tweets based on total engagement, calculated as the sum of likes and retweets. A clustered bar chart is used to compare engagement levels across tweets while incorporating multiple data quality and time-based conditions.

🔧 Visualization Details

Chart Type: Clustered Bar Chart

Metric Used: Total Engagement (Likes + Retweets)

Category: Tweet

📋 Filters & Conditions

Weekend tweets are excluded

Tweet impressions must be even

Tweet posting date must be odd

Tweet word count must be below 30

Visualization is displayed only between 3 PM and 5 PM IST using a DAX-based time control

📈 Key Insight

The chart highlights high-performing tweets by ranking them based on engagement while ensuring consistent data quality through strict filtering rules.
